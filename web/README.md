# Study Spaces — frontend

A mobile-first React + TypeScript UI for the UBC Study Spaces Finder.

## Prerequisites

Node.js 20.19+ (or 22.12+), with npm.

## Run locally

```sh
cd web
npm install
npm run dev
```

Open the local URL printed by Vite.

## Other commands

```sh
npm run build
npm test
npm run preview
```

## Current limitations

This is a **design prototype**, not a deployed or live occupancy system. Any displayed crowding data is illustrative. Location, map tiles, routing, notifications, backend, and persistent reporting are later milestones.
